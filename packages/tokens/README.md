# Styling utilities

The Sass files in `src/styles` generate utility classes from the design tokens.
Include the relevant stylesheet in your Sass build to use its classes.

## Typography

Source: `src/styles/typography/typography.scss`

Typography classes always combine a font size and weight:

```text
.text-{size}-{weight}
```

- Sizes: `xs`, `sm`, `base`, `lg`, `xl`, and `2xl` through `9xl`
- Weights: `thin`, `extralight`, `light`, `regular`, `medium`, `semibold`,
  `bold`, `extrabold`, and `black`

For example, `.text-sm-bold` applies the `sm` font size and `bold` weight.
Font sizes use the responsive `fontClamp` function.

## Spacing

Source: `src/styles/spacing/spacing.scss`

```text
.padding-{spacing}
.margin-{spacing}
.gap-{spacing}
```

Spacing variants are `0`, `px`, `0.5`, `1`, `1.5`, `2`, `2.5`, `3`, `3.5`,
`4` through `12`, then `14`, `16`, `20`, `24`, `28`, `32`, `36`, `40`, `44`,
`48`, `52`, `56`, `60`, `64`, `72`, `80`, and `96`.

Padding uses the padding token scale. Margin and gap use the margin token
scale. Values are emitted in `rem`.

## Borders

Source: `src/styles/border/border.scss`

```text
.border-{width}
.border-{width}-dashed
.radius-{variant}
```

- Width variants: `1`, `2`, `4`, and `8`
- Border style: solid by default; add `-dashed` for a dashed border
- Radius variants: `none`, `sm`, `rounded`, `md`, `lg`, `xl`, `2xl`, `3xl`,
  and `full`

Border widths and radii are emitted in `rem`.

## Effects

Effect classes are generated by the corresponding files in
`src/styles/effects`.

### Shadows

```text
.shadow-{variant}
.drop-shadow-{variant}
```

Variants for both are `sm`, `normal`, `md`, `lg`, `xl`, and `2xl`.

### Blur

```text
.blur-{variant}
.backdrop-blur-{variant}
```

Variants for both are `sm`, `normal`, `md`, `lg`, `xl`, and `2xl`. Blur values
are emitted in `rem`.

### Backdrop opacity

```text
.backdrop-opacity-{percentage}
```

Percentage variants are `10` through `90` in increments of `10`. Each class
applies that opacity to the shared `#111827` backdrop color.

## Example

```html
<div class="text-sm-bold padding-4 gap-2 border-1 radius-md shadow-sm">
  ...
</div>
```
