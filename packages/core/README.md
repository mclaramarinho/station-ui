# `@station-ui/core`

An npm convenience package that installs Station UI's JavaScript token and
SVG asset packages. Import tokens and assets from their individual packages;
this package does not expose a combined runtime API.

```sh
npm install @station-ui/core
```

Install only what you use with `npm install @station-ui/tokens` and/or
`npm install @station-ui/icons`. Dart/Flutter tokens are published separately
as `station_ui_tokens` on pub.dev.
