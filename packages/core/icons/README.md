# `@station-ui/icons`

Source SVG icon assets grouped into `outline`, `solid`, and `custom`
collections. Install with:

```sh
npm install @station-ui/icons
```

Import an SVG by collection and filename:

```js
import arrowRight from '@station-ui/icons/outline/arrow-right.svg';
```

SVG imports require bundler support. The package provides raw assets, not
framework-specific icon components. SVG dimensions and colors can vary between
assets; inspect an icon before relying on `currentColor` or a particular size.
