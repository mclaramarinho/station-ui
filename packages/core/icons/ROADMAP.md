# `@station-ui/icons` roadmap

This package distributes the canonical source SVG assets. The React, Vue,
React Native, and Flutter packages generate their components from these files
so framework output stays aligned with the artwork.

## Next

- Audit SVG markup, viewBoxes, intrinsic sizes, and colors.
- Add automated checks for valid assets and collection naming.
- Document bundler requirements and asset customization limitations.
- Expand generation checks to cover changes in all framework outputs.
