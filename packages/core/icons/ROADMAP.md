# `@station-ui/icons` roadmap

This package currently distributes source SVG assets only; it does not
provide framework-specific icon components.

## Next

- Audit SVG markup, viewBoxes, intrinsic sizes, and colors.
- Add automated checks for valid assets and collection naming.
- Document bundler requirements and asset customization limitations.
- Evaluate platform-specific output only when it can be generated reliably
  from the canonical SVG artwork.
