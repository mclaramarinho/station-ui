# `@station-ui/tokens` roadmap

This package provides JavaScript token constants, Sass variables, and Sass
utility sources from the shared token definitions.

## Next

- Specify and test token naming, value types, aliases, and units.
- Review generated values for JavaScript, Sass, React Native, and Dart
  semantics.
- Expand automated checks for token changes and published package contents.
- Document Sass utility coverage and supported Sass versions.
