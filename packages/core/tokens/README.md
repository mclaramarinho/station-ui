# `@station-ui/tokens`

Design tokens for JavaScript projects and Sass consumers. Install with:

```sh
npm install @station-ui/tokens
```

Import JavaScript constants:

```js
import { ColorSlate500 } from '@station-ui/tokens';
```

Use Sass variables and utilities with Dart Sass 1.71 or newer:

```scss
@use 'pkg:@station-ui/tokens/scss';
@use 'pkg:@station-ui/tokens/styles/spacing/spacing.scss';
```

For Dart and Flutter, use `station_ui_tokens` from pub.dev.
Framework-specific UI components are not included.
