# `@station-ui/core` roadmap

`@station-ui/core` is an npm convenience package that depends on
`@station-ui/tokens` and `@station-ui/icons`. It has no combined runtime API.

## Next

- Keep the dependency versions aligned with the published foundation packages.
- Validate the packed package includes its README and changelog.
- Reassess the umbrella package if its install convenience no longer outweighs
  publishing and maintaining another versioned package.

For token or icon API work, see the [tokens roadmap](tokens/ROADMAP.md) or
[icons roadmap](icons/ROADMAP.md).
