# `station_ui_tokens` roadmap

This pub.dev package exposes generated Dart constants from the shared token
source. It has no Flutter runtime dependency and does not provide widgets.

## Next

- Keep the Dart API stable and verify generated types and units against the
  shared token definitions.
- Validate the full package with Dart analysis and pub.dev's dry-run checks.
- Define a coordinated release process for source token changes and generated
  Dart output.
- Consider Flutter-specific icon assets separately from this token package.
