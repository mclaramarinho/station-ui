# `station_ui_tokens`

Dart design-token constants for Dart and Flutter projects. Install with:

```sh
flutter pub add station_ui_tokens
```

Import the tokens:

```dart
import 'package:station_ui_tokens/station_ui_tokens.dart';

final fontSize = StationTokens.fontSize;
```

Color values are ARGB integers. In Flutter, pass one to `Color(...)` when you
need a `Color`. This package has no Flutter runtime dependency and can also be
used by pure Dart projects.
